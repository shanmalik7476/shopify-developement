# Morrow Shopify Theme

A custom Shopify Online Store 2.0 theme built from scratch for Morrow, an editorial everyday-objects concept store.

## Upload

1. In Shopify admin, go to **Online Store > Themes**.
2. Choose **Add theme > Upload zip file**.
3. Zip the contents of this folder so `layout`, `sections`, `templates`, `snippets`, `assets`, and `config` are at the zip root.
4. Upload, preview, and assign products/collections in the theme editor.

The theme uses Shopify-hosted product imagery by default. The included image files are visual references and can be uploaded through the theme editor or Shopify Files.
